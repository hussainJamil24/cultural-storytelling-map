# Film Narrify: the 1 minute 55 second checklist

**The whole presentation is four minutes, including the video. Export the video at 1:55 or shorter.** Record the real application. Cut out typing and long waits; keep each click and its result. Charalampos can narrate over it. You do not need to show every existing story.

## Before recording

1. Start Narrify using the repository README. Open **http://127.0.0.1:3000**.
2. Prepare three separate windows: **Chrome = contributor**, **Edge = admin**, **Chrome Incognito = logged-out public reader**. Sign the admin in before recording. Ordinary tabs share logins, so use these separate windows.
3. Prepare an approved rehearsal story with **one working photo and one playable audio recording**, plus those same two files for the new upload. The supplied approved stories currently have no confirmed working photo-and-audio pair; use your own photo and short voice recording. See the ready-to-use material below.
4. Test **Generate Companion Card** once. It must say **Generated by Gemini**. Have a separate disposable pending review sample ready for reject/restore; a genuine AI warning is useful. Keep passwords and the API key off screen.

## Optional preparation details

### Ready-to-use rehearsal story

Create and approve one rehearsal copy before recording. During recording, submit a fresh copy with a unique title suffix such as “filming 1”. Both must clearly say they are illustrative demo content.

- **Title:** Demo: A shared table in Limassol
- **Category:** Food
- **Narrative:** “Illustrative demo story created by our team. At a shared table in Limassol, friends brought bread, olives and halloumi and explained the family memories connected to each dish. The conversation showed how food can help people listen to one another and learn about everyday traditions. This entry demonstrates Narrify; it is not a verified historical account.”
- **Location:** click a public place in Limassol on the map.
- **Photo:** use one photo your team took; save it as `demo-shared-table.jpg`.
- **Audio:** record: “This is an illustrative Narrify demo. At a shared table in Limassol, friends share food, memories and the stories behind everyday traditions.” Save a browser-playable audio file and test playback.
- **Comment:** “Food makes a memorable starting point for sharing traditions.”
- **Reply to delete:** “Thank you for contributing to this demonstration.”

Keep existing community stories unchanged. In the supplied snapshot, story 16 has an available photo; stories 1 and 4 have missing photo/audio files. A reference in the database does not guarantee that the file is present. Test your new rehearsal story on the filming computer.

### Avoid confusing the audience

- **Flagged** is the admin tab for **rejected stories**. AI warnings can appear on **pending stories**. They are different. **Restore** makes a rejected story approved/public again. Use only disposable demo entries for this action.
- An AI flag is not guaranteed for every text. Capture a real warning if one is returned; never fabricate one. If none is returned, show the real moderation result and describe the warning feature without claiming a flag appeared.
- A companion card labelled **Generated automatically** is the fallback; it is not live Gemini. Keep the real Gemini badge in the new recording. Existing genuine translations may be cached.
- **Anonymous** hides the name publicly; the contributor still signs in. The companion card is a draft preview. Location labels are approximate; stored coordinates place the marker.
- Demonstrate **one photo plus one audio file**. Story editing/deletion and photo galleries are not implemented screens. Comment/reply deletion is implemented. No raw API or unused backend feature is needed in this video.
- Use short visible cuts for waiting; do not substitute fake screens. Frame at 1920×1080, hide notifications and keep text readable. If the recording is silent, add short captions matching the steps above.
